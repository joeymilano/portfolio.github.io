## 如何使用

将交接包解压到 joeyzhao.cc 的实际代码仓库根目录。压缩包只携带 `docs/portfolio-rebuild/` 下的文档与用户提供的参考截图，不携带、替换或部署网站源码。已有 v1.0 时先比较本地文档改动，再更新同名文档，保留 Agent 已填写的执行证据与用户批准记录。新包为完整替代版，不需叠加两套任务书。

先读仓库原有的 AGENTS.md、README 和构建说明，再按下列顺序阅读：

1. `MASTER_BRIEF.md`：唯一主任务书，已确认方向、双模式、视觉、交互、工程与传播要求。
2. `HERO_SCENE_SPEC.md` 和内嵌原图：完整房间、本人坐姿角色、机位、赛博朋克程度、胶囊切换的具体执行要求。
3. `REFERENCES.md`：主对标、扩展对标、技术资料和访问限制；首看 Basement Blog 与官方制作拆解，再看 Cali。
4. `ACCEPTANCE.md`：视觉、体验、回归、性能、传播与上线门槛。
5. `CONTENT_ASSET_REGISTER.md`：素材和真实信息盘点模板，含本人角色所需资料。
6. `EXECUTION_CHECKLIST.md`：阶段进度与证据索引。
7. `AGENTS_ADDITION.md`：需要时合并到现有项目规则，不能覆盖原 AGENTS.md。
8. `CHANGELOG.md`：v1.1 相对旧包的变化。

如果只拿到 `MASTER_BRIEF.md`，它也可以独立执行；不要因为其他文件未上传而重新询问已确定方向。

保留现有经典作品集，新增完整三维工作室交互版：赵越本人坐在略带赛博朋克气质的工作台前；底部居中胶囊随时切换。经典版用于快速找项目；交互版必须视觉炫酷、有作者性，像轻量探索游戏。书籍、音乐与个人内容重点参考 Cali。需要把真实产品能力与个人品位连起来，并有能用于小红书、YouTube 的真实演示素材。

不要回到纯线性作品集，不做 Mac 桌面复制，不把飞船宇宙改成主任务。不要把个人内容降为页尾附录，不为追求规范而牺牲首屏视觉，不为酷炫增加操作负担。

- `PREFLIGHT.md`：项目路径、分支、已有改动、运行方式、工具能力及真实检查结果。
- `BASELINE.md`：经典版路由、截图、关键功能、构建基线、保护与回滚方案。
