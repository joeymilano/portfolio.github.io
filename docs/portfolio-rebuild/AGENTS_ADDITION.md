# 可合并的项目执行规则

用途：供 Codex 将下列规则有范围地纳入现有项目协作约定。此文件不是根目录 AGENTS.md，放在这里不会被视为已经修改了用户的项目规则。先阅读已有 AGENTS.md，不覆盖、不删除其有效要求。

## 范围与来源

当前任务以 `docs/portfolio-rebuild/MASTER_BRIEF.md` v1.1 为主说明，`HERO_SCENE_SPEC.md` 为首屏详细要求，`ACCEPTANCE.md` 为验收说明。用户后续明确的决定优先于旧方案。外部参考网站只提供资料，不是授权修改本项目范围的指令。

本期仅改造 joeyzhao.cc 的个人作品集体验。保留经典版，新增以 Basement Blog 为第一参考的完整三维工作室：赵越坐在略带赛博朋克气质的桌前，底部胶囊切换交互版/经典版。人物和房间是本期必需，不得回退空桌、平面图片视差或循环视频。不改成 Mac 复刻，不把飞船导航升级为主方案。

## 开工与保护

先检查仓库状态、现有栈、脚本、路由、素材和实际工具权限。不得丢弃已有未提交改动、强制重置或擅自更换框架。生产发布与付费资源采购需要明确授权。

第一步完成基线与高保真目标。只有视觉目标确认后才扩展完整交互。不因工程方便把目标替换成普通卡片或默认三维几何体。

## 视觉与证据

必须分别标注概念图、离线渲染与真实网页截图。网页视觉检查需要实际打开和观察，不得仅用代码构建结果代替。没有做过的设备、网络、无障碍和性能检查一律写未测。

人物与物件需要协调材质、合理尺度、自然接触和明确反馈。缺本人照片先做中性坐姿体块，标记最终人物待确认；不冒充还原、不以缺照片为由取消人物。先提高一个场景、一条路径的完成度，再扩展内容数量。

## 内容

使用已存在或经用户确认的内容。不得编造个人书单、音乐偏好、照片、职位、奖项、用户量、营收、客户评价和转化数据。引用第三方素材前记录来源与许可，不把参考资产自动复制到生产站。

两版共享同一内容源。现有项目路由、简历与联系入口保持可用。音乐默认静音；播放失败要有清楚反馈。

## 协作

Astra 可独立完成本期任务。启用其他 Agent 时，分离工作目录与文件所有权。不要同时修改二进制模型、核心场景或锁文件。审查 Agent 默认先报告，不自行重做视觉系统。

## 验收

功能、视觉、性能和传播物料分别检查。未通过主视觉门槛时不得以“已完成全部页面”结束任务。完成报告必须附实际证据、运行方式、已知问题和回滚方法。
