# ID.AURA — 大幅设计重构方案

> 标杆：Lotus Hyper OS（iF 设计奖 ×2 + Red Dot）｜适配：WebGL/Three.js｜目标：拿奖级
> 作者：Joey Zhao · 2026-07-27

---

## 一、设计主张

把车机从**"装饰性 UI 浮层"**升级为**"以 3D 数字孪生为主角、场景化动态重组的驾驶智能界面"**。

- 对标 Lotus 拿奖逻辑：数字孪生 3D + 场景化重组 + 跨模态换色 + 物理仪式动效
- 用 **Rivian cel-shaded（风格化 3D）** 替代 Lotus 写实孪生——WebGL 性能可控、视觉差异化更强
- 建立大众 ID.AURA 自己的**"斜切几何"视觉基因**（致敬 Lotus 斜切字体/图标 + 大众 ID 锐利感）

## 三、现状诊断（五维欠债）

1. **美术资源**：Cluster 背景是低质隧道照片、道路是一条贝塞尔曲线、自车是 3 根线段；全项目仅 16 个通用 Phosphor 图标；3 个 Google 通用字体；无动效美术。
2. **Cluster 信息架构**：元素空洞（速度/能量/一条路/转向卡/档位），缺 ADAS 可视化、缺场景态、无场景化重组；照片与 Canvas 是两个世界。
3. **视觉质感**：底层仍是科幻 HUD 语言（青描边+bloom+glow）；玻璃 CSS 模拟无折射；信息单平面无 Z 轴。
4. **动效**：模式硬切；道路不流动；微交互无反馈。
5. **概念锚点**：无安全前置叙事、无意图识别、无场景重组、无启动仪式。

## 四、Phase 0 — 视觉基因重建（基础 · 1–2 天 · 风险低）

### 0.1 配色体系（3 级深色 + 模式色）

```css
:root {
  /* 3 级深炭色阶（替代纯黑/单一深色）*/
  --bg-deep:  #0A0D10;   /* 最底层 — 主背景 */
  --bg-mid:   #11161A;   /* 中间层 — 大面板 */
  --bg-rise:  #1A2128;   /* 抬升层 — 卡片表面 */
  --bg-glass: rgba(20, 26, 33, 0.55);

  /* 文字 */
  --ink:        #F2F5F7;  /* 主文字 / 安静白数字 */
  --ink-bright: #F8FAFB;  /* 关键数字 */
  --ink-dim:    #8A95A1;  /* 次级标签 */
  --ink-faint:  #56636C;  /* 辅助/单位 */

  /* 模式强调色（切换时整体换色，总面积 ≤5%）*/
  --aura:  #54D3E3;   /* AURA/Comfort — 保留大众 ID 青蓝 DNA */
  --eco:   #6FD9B4;   /* ECO — 冷绿 */
  --sport: #FF4D2E;   /* GT/Sport — 橙红（Porsche/Lotus Sport 共识）*/
  --track: #FF3B30;   /* Track — 更烈红 */

  /* 功能色 */
  --warn:  #E6A877;
  --recup: #75E2BD;   /* 能量回收 — 正向绿 */
}
```

**原则**：强调色只用于主动元素/关键状态/当前模式锚点，背景绝不大面积铺色。模式切换 = 强调色全局替换 + 氛围辉光联动。

### 0.2 字体体系（几何切割基因）

| 角色 | 字体 | 字重 | 用途 |
|---|---|---|---|
| **Display 数字** | `Chakra Petch`（免费，几何切角） | 200/300 大号 + 500 单位 | 速度/功率/电量/距离 |
| **正文/标签** | `Manrope`（保留） | 400/500 | UI 文字、卡片标题 |
| **数据戳** | `Sometype Mono`（保留，克制） | 400 | 时间戳、坐标（仅极少数） |
| **强主张** | `Michroma`（保留） | 400 | 品牌 logo / 模式大标题 |

- 数字一律 `font-variant-numeric: tabular-nums`（等宽，跳动不抖）
- **字号比 8x**：主数字 96–128px Thin，单位/标签 11–13px Medium
- 删除 Michroma 在正文场景的滥用（当前 HUD 到处是 Michroma，喧闹）

```html
<!-- index.html 新增 -->
<link href="https://fonts.googleapis.com/css2?family=Chakra+Petch:wght@300;400;500;600&display=swap" rel="stylesheet">
```

### 0.3 图标体系（40+ 斜切品牌图标）

在现有 16 个 Phosphor 基础上**扩展 + 品牌化**，建立统一几何语言：

- **统一描边 1.75px**（@1x），线性优先，圆角统一 2px
- **斜切收脚**：每个图标收尾处加 30° 切角（致敬 Lotus monogram diagonal + 大众 ID 锐利感）
- 继续用 CSS `mask` + SVG 机制（已验证可用）

**新增图标清单（按域分组）**：

| 域 | 图标 |
|---|---|
| **ADAS** | 车道保持、ACC 跟车、盲区监测、自动泊车、前车碰撞预警、交通标志识别、驾驶员监控 |
| **能量** | 能量回收、充电中、功率流（驱动/回收双态）、充电口、电池健康 |
| **模式** | ECO、COMFORT/AURA、SPORT/GT、TRACK、INDIVIDUAL |
| **车辆** | 车门（四门独立）、车窗、后视镜、后备箱、引擎盖、空调风向、座椅加热/通风 |
| **导航** | AR 转向、路口放大、限速、电子眼、服务区 |
| **媒体** | 播放/暂停/上下首（已有）、音源切换、声场、降噪 |

### 0.4 玻璃/质感

- 玻璃卡片：`backdrop-filter: blur(24px)` + `--bg-glass` + **顶边高光** `inset 0 1px 0 rgba(255,255,255,0.06)`
- 去除 sci-fi 描边光（box-shadow 青色 glow），改内描边 `rgba(150,190,210,0.08)`
- Bloom 维持低位（已降到 0.08，保留）

## 五、Phase 1 — Cluster 重构（核心 · 2–3 天 · 风险中）

**Joey 最不满的部分。完全重写 `cluster.js`。**

### 设计：三层 Z 轴 + 四模式档

```
┌─────────────────────────────────────────────┐
│  顶层 · ADAS 感知叠层                         │  车道线 / 前车 box / ACC 环 / 盲区
├─────────────────────────────────────────────┤
│  中层 · 核心 EV 仪表环                        │  功率表（正负驱动/回收）+ 速度环
│         + 左速度 / 右能量 / 转向卡            │
├─────────────────────────────────────────────┤
│  底层 · cel-shaded 风格化道路场景             │  透视车道（流动）+ 天际线剪影
└─────────────────────────────────────────────┘
```

### 5.1 底层：风格化道路场景（废弃隧道照片）

替代 `assets/art/cluster-night-tunnel.jpg`，用 **Canvas 2D** 绘制 cel-shaded 道路：

- **双车道透视**：两条向消失点收缩的车道线，**持续流动动画**（车道线段向下滚动 → 强烈的"在前进"体感）
- **cel-shaded 分层**：远山剪影（3 层，深→浅）+ 路面色块（非渐变，硬边色阶，cel-shaded 特征）
- **路面反光**：自车前灯锥（轻量径向）
- 色调随**驾驶模式整体换色**（AURA 青 / GT 橙红 / ECO 绿）

> 技术上 Canvas 2D 即可胜任（性能远优于 Three.js），与现有 cluster.js 架构兼容。

### 5.2 中层：核心 EV 功率表（致敬保时捷）

- **中央半圆功率表**：上半弧=驱动功率（青/橙红），下半弧=回收功率（绿），实时指针
- **速度**：功率表中心叠加大号 Thin 数字（Chakra Petch 200，120px+）
- 外圈：速度刻度环（极细，克制）
- **这是 EV 仪表的教科书处理**——不再用圆形转速表（油车隐喻）

### 5.3 顶层：ADAS 感知叠层

- **车道线高亮**：当前车道两侧青色描边（虚线流动）
- **前车 detection box**：方框 + 距离数值（m）+ TTC 时间
- **ACC 状态环**：跟车目标高亮
- **盲区指示**：左右后视镜区域警示

### 5.4 四模式档（信息重新分区 — Lotus 场景化重组）

| 模式 | 布局 | 强调色 |
|---|---|---|
| **Pure** | 仅速度 + 导航箭头（高速/ADAS，最克制） | 单色青 |
| **Drive** | 功率表 + 道路 + 基本 ADAS（默认） | AURA 青 |
| **Energy** | 能量流可视化居中（充电/回收场景） | 回收绿 |
| **GT** | 功率表放大 + 性能数据（0-100、G 力） | 橙红 |

**切换动效**：信息分区平滑重组（GSAP，元素位移 + 透明度），不是硬切。

## 六、Phase 2 — 3D 数字孪生融合（2–3 天 · 风险高 · 架构变）

把 Showroom 的 3D 车与 Console 融合，实现"3D 主角 + UI 浮层"。

### 6.1 Console 主画面 = 3D 车辆孪生

- Console 中央换成 **cel-shaded 3D 车模**（Three.js ToonMaterial 替代 MeshPhysicalMaterial）
- **车模可点控**（致敬 Lotus 3D Garage / 极氪）：点车门开门、点充电口、换漆、开车灯、开后备箱
- 地图/媒体/空调退为**侧边浮层卡片**（Z 轴中层），不遮挡 3D

### 6.2 cel-shading 技术实现

```js
import { MeshToonMaterial } from 'three/addons/materials/MeshToonMaterial.js';
// 车体：MeshToonMaterial + 渐变贴图（3-5 级色阶）
// 道路场景/环境同样 toon 化
// 性能：toon 比 physical 快 30-40%，WebGL 友好
```

### 6.3 风险与回退

- 架构改动大（main.js 的 layer 切换逻辑要调）
- **回退方案**：若 cel-shading 车模效果不理想，保留 Showroom 写实车，仅在 Console 用 cel-shaded 道路/环境

## 七、Phase 3 — 动效系统 + 概念锚点（1–2 天 · 风险低 · 拿奖关键）

### 7.1 动效系统

| 场景 | 动效 | 曲线 |
|---|---|---|
| **模式切换** | Y 轴翻转 + 信息重组（致敬 Lotus 可翻转屏） | `cubic-bezier(0.16, 1, 0.3, 1)` 快出慢回 |
| **微交互** | 按钮/卡片按下：轻微下沉 + 辉光内收 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| **数据更新** | 数字滚动（tabular-nums 保证不抖） | spring 轻微 |
| **驾驶中** | 动效克制（更快、更不抢眼）— 安全优先 | — |
| **驻车** | 动效放开（3D 全开、探索性） | — |

### 7.2 概念锚点（iF 评审维度）

**① AURA 意图层（EQS Zero Layer 本地化）**
- 根据时间/路况/电量/日历**主动推送**场景卡："18:00 周五 · 路况拥堵 · 建议走 A100，电量够往返"
- 驻车时浮现，驾驶中退场

**② 安全前置叙事**
- ADAS 状态永远在最前层（Z 轴顶层）
- 接管/警告用"光刃"事件提示（替代 toast）：一道横扫光 + 信息

**③ Boot Ritual 启动仪式**
- 上电序列：黑屏 → 一道光横扫唤醒 → 3D 车浮现 → UI 层叠展开 → 就绪
- 替代当前静态 loader

**④ 跨模态辉光（屏+氛围灯）**
- 模式切换时，屏幕边缘 + 整体背景辉光联动换色（模拟 Lotus 屏+氛围灯）

## 九、技术实现要点

- **不改技术栈**：Three.js / GSAP / Canvas 2D / Web Audio 全部保留
- **cel-shading**：`MeshToonMaterial` + 渐变色阶贴图
- **Cluster**：维持 Canvas 2D（性能好），重写绘制逻辑
- **字体**：新增 Chakra Petch（Google Fonts），其余保留
- **图标**：扩展 SVG 库，继续 CSS mask 机制
- **可逆**：每个 Phase 独立分支/commit，可回退

## 十、不在本次范围（明确边界）
