# ID.AURA — Cluster & Console 视觉大幅升级方案

> 目标：从「精致的原型」跃迁为「世界级的概念车 HMI 作品」——科幻电影级的精密仪器感。
> 对标：Lotus Hyper OS（iF 2024 / Red Dot 2024）、Territory Studio 电影 UI（Blade Runner 2049）、Porsche Taycan 曲面仪表、Lucid Air、蔚来 ET9、仰望 U8。

## 一、设计诊断：当前与世界级的差距

### Cluster 现状（证据：qa/cluster-after.jpg + 代码审计）

| 维度 | 现状 | 世界级标杆 | 差距根因 |
|---|---|---|---|
| 背景 | 一张 AI 夜景照片铺满，发灰发闷，颗粒感与矢量 UI 冲突 | 路特斯：全 3D 实时场景；电影 UI：照片大幅单色化压暗作"底" | 照片"太实"，没有电影调色（压暗/去饱和/单色/颗粒） |
| 主仪表 | 一根渐变圆弧 + 大数字，**无刻度** | Taycan：精密刻度环，0.5px 发丝刻度 + 分段数字 | 缺"仪器刻度"这一精致感核心来源 |
| 信息密度 | 中央巨大而空，四周稀疏 | 三层密度：主读数 → 次级环 → 微型数据带 | 只有一层密度，缺微型数据带（电机温度/扭矩/胎压/G 值） |
| 材质 | 平色 + shadowBlur 辉光 | 多层玻璃、金属边框、噪点、扫描线、体积光 | 无材质系统，只有"发光"一种手段 |
| ADAS | 线条示意车道 + 前车角框 | 路特斯：3D 车模 + 感知点云 + 车道填充发光 | 缺感知环境的"体积感" |
| 色彩 | 青色一统，灰阶层次不足 | 深空底 + 单主色 + 2–3 点缀 + 大量灰阶 | 对比度曲线没拉开 |

### Console 现状（证据：qa/console-check.jpg + 代码审计）

| 维度 | 现状 | 世界级标杆 | 差距根因 |
|---|---|---|---|
| 3D 车模 | 黑乎乎一坨，正后角度尴尬，只有一盏主光 | 路特斯：车即主角，影棚三点光 + 镜面地台 + 实时遥测 | 打光业余、地台是死黑圆盘、角度不对 |
| 卡片 | 半透明圆角矩形，塑料感 | 光子玻璃：blur + 1px 渐变描边 + 内阴影 + 噪点 | 无材质层次 |
| 地图 | 真实数据但视觉"工具感"，线条细弱 | 深色 cartography + 发光道路 + 建筑体量发光描边 | 配色没风格化 |
| 卡片内容 | 媒体=封面+进度条；空调=温度±；车辆=续航 | 每张卡是一个"微应用"：频谱/声场、座舱分区、健康矩阵 | 内容密度不足 |
| 仪式感 | 静态 | 路特斯 Dynamic Console：场景驱动的智能变形 | 场景系统已有（6 scenario），但视觉表现力弱 |

**一句话诊断：** 骨架（架构/数据/交互）已是专业级，缺的是**"电影级的表面"**——刻度、材质、光、密度、调色。

## 二、设计方向：「APEX COCKPIT · 光子仪器」

不把 Cluster/Console 当"车机 UI"，而当**科幻电影里的精密仪器**——飞船控制台 × 精密腕表 × 摄影棚。

### 三大设计支柱

**1. 精密仪器感（Instrument Precision）**
- 0.5px 发丝刻度、分层同心圆环、微型数据带、单声道数字字体、严格 8px/4px 对齐网格
- 参考：Blade Runner 2049 UI、IWC 腕表、太空舱仪表
- 精致感的来源 = "看得见的精密排布"，不是更多发光

**2. 光子材质（Photon Material）**
- 光子玻璃：backdrop-blur + 1px 顶部高光渐变描边 + 内阴影 + 微噪点
- 辉光分层：近实远虚（实线 → 柔光 → 体积雾），拒绝"一片糊光"
- 电影材质：film grain、扫描线、对角玻璃反光、暗角
- 参考：Lotus Hyper OS、Tron Legacy

**3. 实时剧场（Live Theatre）**
- 所有数据持续微动（呼吸感），无一像素是死的
- 模式/场景切换 = 元素流体迁移（已有 GSAP FLIP 机制，强化）
- 色彩叙事：Pure 青 / Drive 青蓝 / Energy 绿 / GT 橙红，跨屏联动（已有 `--view-accent` 钩子）

## 三、Cluster 升级规格

### 3.1 布局重构：「三舱同心仪器」

保留中央速度核心（驾驶仪表的锚点），两侧各开一个"玻璃仪器舱"，把散落的信息收进舱内并大幅加密。

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部微型状态带  ⏐ telltales · 时间 · 温度 · 信号 · 档位 ⏐        │
│                                                                │
│  ┌─左仪器舱─┐      ┌──── 中央仪器舱 ────┐      ┌─右仪器舱─┐     │
│  │ 功率 kW   │      │                    │      │ SOC 环    │     │
│  │ 扭矩分配  │      │   主速度刻度环       │      │ 续航大数   │     │
│  │ 电机温度  │      │   + 速度滚筒数字     │      │ 能耗曲线   │     │
│  │ G-force  │      │   + ADAS 车道/前车  │      │ 回收功率   │     │
│  │ 0-100   │      │   + 导航下一动作     │      │ 行程数据   │     │
│  └─────────┘      └────────────────────┘      └─────────┘     │
│                                                                │
│ 底部模式带  PURE / DRIVE / ENERGY / GT  +  ODO · TRIP · AVG    │
└──────────────────────────────────────────────────────────────┘
        背景：电影调色的夜间公路（大幅压暗 + 单色青黑 + 颗粒）
```

### 3.2 主仪表环重做（gauge.js —— 精致感的核心战场）

- **外环刻度带**：0–240 km/h，细分刻度每 2 km/h 一根 0.5px 发丝线，每 20 一根 2px 主刻度并带数字（0/40/80/…/240，Chakra Petch 小号）；当前速度对应刻度"点亮"为主色，已过刻度半亮、未来刻度 18% 灰
- **内侧功率弧**：DRIVE（右半）/ RECUP（左半，绿）分区，各带峰值保持标记（最近 5s 峰值的一根亮线）；指针后方加**渐变拖尾**
- **能量粒子流**（已有 26 粒子升级）：数量升至 40，加拖尾（每粒子画 3 帧渐隐残影），回收时反向变绿
- **速度数字**：三层字级——96px 滚筒主数字（Technor）+ 14px "KM/H" mono 小字 + 下方 kW 实时读数；数字背后加径向辉光晕（`drop-shadow` 已有，加强层次）
- **环中心**：模式切换时中心微缩缩放（已有 gaugeScale）+ 一圈"确认脉冲"

### 3.3 左仪器舱 · 性能舱（新增）

玻璃舱（Photon Glass 材质），内含：
- **实时功率**：大号 kW 读数 + 微型 sparkline
- **扭矩分配**：前/后电机两条横向发光条，随加速动态分配
- **电机温度**：前/后两条微条（°C），超温变琥珀
- **G-force 圆盘**（已有升级）：加刻度环 + 轨迹尾迹（最近 2s 的 G 点连成渐隐轨迹）
- **0–100 计时**：GT 模式下升为大读数

### 3.4 右仪器舱 · 能量舱（新增）

- **SOC 环**：细刻度环形仪表（0–100%），当前电量弧 + 剩余续航大数字
- **能耗曲线**：渐变填充 + 顶部发光描边的 sparkline（近 60s）
- **回收功率**：绿色 kW 读数，回收时脉冲
- **行程数据**：TRIP A / ODO / AVG kWh·100km⁻¹，mono 小字三行

### 3.5 ADAS 感知层升级

- **前车 bracket**：四角括号 + 顶部测距标尺（刻度线）+ "50 M · TTC 2.4 S" mono 微标签；ACC 锁定时括号合拢动画
- **车道**：车道区域加**微妙渐变填充发光**（路特斯式），车道线保持发光描边
- **盲区**：侧后雷达扇形 + 警示车影图标
- **限速牌**：EU 标准圆形红圈样式，超速琥珀脉冲（已有，精修）

### 3.6 顶部微型状态带（重排 + 加密）

telltales 重绘为精密线性图标（1.5px 描边，统一 16×16 网格）：转向/ADAS/安全带/回收/TPMS/远光/雾灯/电量；右侧 时间 · 车外温度 · 信号 · 档位（P/R/N/D）。

### 3.7 背景与材质（电影调色）

- **换素材**：外网 CC0 高质量夜间公路/隧道/城市高架 POV 摄影（Unsplash/Pexels/Openverse），≥2K，替换 `assets/art/cluster-night-road.jpg`
- **电影调色**（ImageMagick 批处理，是"后期"非"生成"）：压暗至 35% 亮度、去饱和 60%、青黑单色化（duotone 趋向 #0a1418 → #54d3e3 高光）、加 vignette、可选轻颗粒
- **材质叠加层**（CSS/伪元素）：film grain（SVG feTurbulence 噪点，2% 透明）、极淡扫描线、对角玻璃反光渐变、四边暗角
- **HORIZON 同步**：换图后必须同步 `js/cluster/index.js:248` 的 `HORIZON=0.34`（车道灭点与照片地平线硬绑定）

### 3.8 四模式保留并强化

PURE / DRIVE / ENERGY / GT 四档机制（`MODES` + `LAYOUT_TARGET` + GSAP 迁移）已是专业设计，保留；升级为：
- 每档切换时**三舱元素流体迁移**（性能舱在 GT 展开为全宽，能量舱在 ENERGY 展开）
- 主色平滑过渡（`--mode-hue` 已有）+ 背景调色随模式微调（GT 偏暖黑、ENERGY 偏冷绿黑）

## 四、Console 升级规格

### 4.1 中央 3D 舞台重做（main.js / scene.js —— 震撼感核心）

**"车即主角"，影棚级呈现：**

- **相机**：从现在的正后低位，改为**低机位 3/4 前侧**（电影海报角度），缓慢环绕 + 微浮动（呼吸感）
- **三点影棚光**：
  - Key 主光：冷白 `#dfe9ff`，大角度柔光（已有，强化 + 阴影精细化）
  - Rim 轮廓光：主青 `#54d3e3`，从侧后勾勒车身腰线（已有，提亮）
  - **新增 Fill 底光**：微弱暖光从地面反弹，让车底不死黑
- **镜面地台**：`CircleGeometry` 升级为**反射地台**（Reflector 或高 metalness + envMap 近似），车身在地面有真实倒影——这是"贵"的关键一笔
- **发光地环**（已有升级）：双层环——内环实、外环虚，随车辆状态呼吸脉动；充电场景变绿流
- **车漆**：MeshPhysicalMaterial 调 `clearcoat≈1`、`clearcoatRoughness≈0.08`、`metalness≈0.9`，加细微 flake 噪点法线（金属漆质感）
- **扫描光环**：一道光环沿车身 Z 轴缓慢扫描（科幻"扫描"仪式感，X-RAY 的日常版）
- **热管理 heatmap**（已有强化）：更细腻的双色渐变 + 流动动画
- **环绕微尘**：体积光里漂浮的细微尘埃粒子（Points，极慢漂浮）——影棚空气感
- **HDRI**：可换/补一张 Poly Haven 摄影棚 HDRI（`studio_small_09` 已在，评估是否更亮）

### 4.2 卡片系统材质重做（Photon Glass）

统一升级所有 rail 卡片 + 地图卡 + dock：
- `backdrop-filter: blur(18px) saturate(1.4)`
- 1px 渐变描边：顶部 60% 白 → 侧底 8% 白（模拟玻璃厚度受光）
- 内阴影：`inset 0 1px 0 rgba(255,255,255,.06)`
- 微噪点纹理（2%）
- hover：描边提亮 + 卡片微抬升
- **卡片头部统一**：左侧 2px 主色条 + mono 小号标签 + 右上角状态点（绿=正常）

### 4.3 卡片内容加密（每张卡 = 微应用）

- **媒体卡**：专辑封面提取主色做**卡边光晕外溢**；频谱条 12→24 根、圆润端头、峰值保持线；加一行滚动歌词（模拟）；加声场模式（DRIVER/ALL）
- **空调卡**：升级为**座舱分区俯视图**——简笔座舱 SVG，四区温度独立显示，风向流线动画（3 条流动曲线），座椅加热/通风图标状态
- **车辆卡**：升级为**车辆健康矩阵**——SOC 大环 + 续航 + 12V 电池 + 四轮俯视图（每轮胎压 bar + 温度 °C）+ 能耗曲线 + 下次保养里程
- **新增 充电卡**（PARKED/CHARGING 场景优先）：充电功率曲线、当前 kW、预计充满时间、目标电量滑块

### 4.4 地图风格化（console-map.js buildStyle 改色，纯数据表达式）

- 背景 → 深空蓝黑 `#05070c`
- 道路分级：主干道青色微光（`#2b4a55` casing + `#3d6a78` fill）、次级 `#1a2230`
- 路线：霓虹青 + 外发光（已有强化），加**流动光点脉冲**（沿路线推进的亮点）
- 建筑 fill-extrusion：顶面加 1px 青色发光描边（伪 3D 城市夜景）
- 水系：深青 `#0a1a22` 微光
- ego marker：升级为带朝向视锥的定位箭头（Tesla 式 FOV 扇形）

### 4.5 状态栏与 dock

- 顶部：加蓝牙/信号/通知精密 SVG 图标；JOURNEY ACTIVE 加呼吸点
- 底部 dock：毛玻璃 pill 升级为 Photon Glass；X-RAY 按钮加激活态发光

## 八、成功标准（对标验收）

1. **刻度精密**：主仪表有完整 0–240 刻度带 + 数字，一眼"仪器"而非"图形"
2. **材质分层**：玻璃/辉光/噪点/暗角四层材质清晰可辨，无一处死平
3. **车即主角**：Console 车模有影棚三点光 + 地面倒影，截图可直接当海报
4. **密度三层**：主读数 / 次级环 / 微型数据带，信息丰富但不吵
5. **电影调色**：背景是"调过色的电影画面"，不是"一张照片"
6. **活的数据**：每一帧都有微动，3 秒看一次和看 30 秒都有新细节
7. **模式即叙事**：四模式切换是流体变形 + 色彩叙事，不是换皮
